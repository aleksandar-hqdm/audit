Where the volume is (and where it is not)

The strategic tension

Almost all the volume is top-of-funnel reference content (the AI-Overview-eaten kind). The biggest pool is the ICD-10 / code cluster. Deduped of query variants, the mental-health subset is ~133k/mo (your on-audience target, where you are mostly absent). A separate ~286k is general-medical codes (hypokalemia, transaminitis, heart failure) that Twofold wins as a general medical scribe: real volume, but the searchers are doctors and coders, not therapists, so it only matters if Mentalyc decides to expand beyond therapy (a positioning call). And the genuine buy-intent cluster is tiny (~2,500/mo). So you cannot recover on buyer keywords alone: win the mental-health code cluster back as tools, and convert far better.

The genuine buy-intent cluster (~40 terms, ~2,500/mo)

Buy-intent means searches from someone actively shopping for an AI scribe (for example 'ai scribe for therapists', 'hipaa compliant ai note taker', 'best ai for therapists'), not someone looking up how to write a note. There are only about 40 such terms, ~2,500 searches/mo in total: real buyers, but very few of them, which is why the recovery cannot lean on buyer-keyword search.
