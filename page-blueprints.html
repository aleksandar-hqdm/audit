Page blueprints: exactly what to build

The competitors' pages are not one-offs; each silo runs a repeatable template. Here is each one reverse-engineered into a buildable spec: the URL and hub, the section-by-section skeleton, the required elements and schema, the internal-linking pattern, and the naming convention. Hand these to a content or dev team and they can ship.

The target architecture: hub-and-spoke silos

Every competitor silo runs the same shape: a hub page that lists and links every spoke (18 to 33 internal links per hub), and each spoke links back to the hub, to 6-10 sibling pages, and down to a product CTA. That dense interlinking is what builds topical authority and lifts the whole cluster. Read the map top to bottom: green silos are already live on mentalyc.com (worksheets and note examples); red are the high-value silos still to build.

The six blueprints

PROGRAMMATICA. ICD-10 / CPT code detail page

Silo hub: /icd-10 and /cpt-codes. The ~133k/mo cluster you are mostly absent from.
Evidence: Twofold /medical-codes pages avg 1,565 words, 9 H2, a table, FAQ schema, author (3-4 of 4 sampled); Supanote /cpt-codes add reimbursement rates. Hubs ('Medical Coding Hub', 'Guide to CPT Codes') interlink 18-33 spokes.
Mentalyc now: You have an /icd-10-codes URL but it is an empty stub (no H1, no code pages), plus a few ICD posts loose in /blog. Of 10 code SERPs tested, Mentalyc ranks on just one (its lone F43.23 post at #3); on anxiety, depression, ADHD, bipolar and OCD ICD-10 and on 90837 CPT it is absent, with icd10data, NCBI and the AMA holding #1. You run hubs elsewhere, so this is populate-and-wire, not a new capability.
BUILD THIS
URL /icd-10/f41-1-generalized-anxiety (hub /icd-10) H1 F41.1 ICD-10 Code: Generalized Anxiety Disorder [box] Quick answer: definition + billable? (AIO-extractable) H2 What is the F41.1 code? H2 Diagnostic criteria [TABLE] H2 When to use it (scenarios) H2 How to document the session [note example] H2 Reimbursement & billing [TABLE] H2 Common coding mistakes H2 Related codes [6-10 sibling links] FAQ (FAQPage) "Is F41.1 billable?" "F41.1 vs F41.9?" [byline] Reviewed by [LCSW], updated [date] [CTA] Generate a compliant F41.1 note → Try Mentalyc
REQUIRED ELEMENTS
  • Schema: MedicalWebPage + FAQPage + BreadcrumbList + Person
  • ~1,400-1,600 words
  • 1-2 tables (criteria, reimbursement)
  • Reviewer byline + visible updated date (YMYL E-E-A-T)
  • Hub link + 6-10 sibling-code links + product CTA

Why it wins: It is the largest single demand cluster you are missing (~133k/mo across ~201 codes), competitors win it with zero backlinks (pure structure + breadth + internal linking), and your domain authority (rank 252, ahead of them) means the same page should rank better for you. Generate programmatically from the ~201 mental-health codes + the mental-health CPT set.

LINK MAGNETB. Comparison / review page

Silo hub: /compare. The only content type that earns real links.
Evidence: Twofold /compare pages avg 1,579 words, 8 H2, comparison table, FAQ, author, and the silo earns 170 referring domains. Naming: '[X] Review: Features, Pricing & Who It's For (2026)', '[X] vs Twofold', 'Best [X] Alternative'.
Mentalyc now: Zero comparison pages. You already rank #1 for 'mentalyc vs upheal', 'upheal review' and 'ai therapy notes comparison' with one-off content, so a real /compare silo would compound, mainly for links and AI-citation (the searches themselves are thin).
BUILD THIS
URL /compare/mentalyc-vs-upheal (+ /upheal-review, /upheal-alternatives) H1 Mentalyc vs Upheal (2026): Honest Comparison [box] Verdict: who each is best for (AIO) H2 At a glance [TABLE: features x both] H2 Upheal overview (fair) H2 Features compared H2 Pricing compared [TABLE] H2 Pros & cons of each H2 Who should choose which H2 The honest verdict FAQ "Is Upheal HIPAA compliant?" ... [CTA] Try Mentalyc free
REQUIRED ELEMENTS
  • Schema: Article + FAQPage + BreadcrumbList + Person
  • ~1,500-1,700 words; 2 tables (features, pricing)
  • Cover: vs Upheal / Blueprint / Supanote / SimplePractice AI; "alternatives"; competitor-brand reviews
  • You rank #1 for "mentalyc alternatives" and "vs" terms now, but Supanote and Twofold crowd the page; a real silo holds it

Why it wins: It is the single page type that attracts links honestly (170 RD to Twofold's), it intercepts high-intent 'vs / review / alternative' searches, and it gives the AI assistants extractable verdicts to cite.

CONVERSIONC. Exact-match BOFU landing page

One page per buyer term. Standalone, not the broad product page.
Evidence: Supanote /hipaa-compliant-ai-therapy-notes: 1,052 words, exact-match URL, Product schema, FAQ(7), and UTM-tracked CTAs throughout (hero/navbar/inline). Short and conversion-focused beats long and broad here.
Mentalyc now: Broad product pages with no Product/AggregateRating schema. Supanote's exact-match page (Product schema, FAQ, UTM-tracked CTAs throughout) outranks you #1 vs your #7 for 'hipaa compliant ai therapy notes'. You have no exact-match page for it.
BUILD THIS
URL /ai-therapy-note-generator (one per buyer term) H1 AI Therapy Note Generator: Notes in 2 Minutes [hero CTA] Try free, no card + HIPAA/4.6 badges H2 Loved by 30,000+ therapists [proof] H2 How it works [3 steps] H2 Built for compliance [4 points] H2 Built for your practice [features] H2 Your data, secured [4 points] [demo] Sample input → finished note FAQ (FAQPage) exact-match questions [CTAs, ~8-12] UTM-tracked throughout
REQUIRED ELEMENTS
  • Schema: Product + SoftwareApplication + AggregateRating + FAQPage
  • ~1,000-1,200 words, exact-match slug
  • ~8-12 tracked CTAs (UTM-tagged)
  • Sample-output / demo block (the top buyer objection: note quality)
  • Build for: ai-therapy-note-generator, hipaa-compliant-ai-progress-notes, ai-scribe-for-therapists, automated-therapy-notes

Why it wins: Supanote out-ranks and out-converts on BOFU with these, not with long pages. Exact-match URL + intent-matched copy + CTA density is the formula.

BOFU BREADTHD. Solutions / use-case page

Silo hub: /solutions. Captures use-case + specialty intent.
Evidence: Twofold /solutions/affordable-ai-scribe: 4,232 words, persona-driven, a manual-vs-AI table, FAQ, Service + Breadcrumb schema. Sections: benefits grid, manual-vs-AI, persona fit, social proof, internal-link hub.
Mentalyc now: No /solutions silo and no use-case or specialty landing pages; one broad product page per feature, and no manual-vs-AI comparison page anywhere.
BUILD THIS
URL /solutions/ai-scribe-for-group-practices H1 AI Scribe for Group Practices H2 Benefits [feature grid] H2 Manual vs Mentalyc [TABLE without/with] H2 Built for [personas] [3-4 personas] H2 Loved by clinicians [proof] H2 Learn more [internal links to silos] FAQ + breadcrumb nav
REQUIRED ELEMENTS
  • Schema: Service + FAQPage + BreadcrumbList
  • ~2,500-4,000 words
  • Build per use-case (solo, group, telehealth) and per specialty
  • Doubles as an internal-link hub into the other silos

Why it wins: Captures the use-case and specialty long tail, carries a manual-vs-AI table that sells, and routes link equity across the silos.

MOFU CAPTUREE. Template / worksheet page

Silo hub: /templates and /worksheets. The missing lead-capture layer.
Evidence: Twofold and Supanote /templates pages (~1,000-1,100 words) list a template + a worked example. Hubs interlink 18-33 template spokes.
Mentalyc now: You already run a /worksheets-and-cheatsheets hub (103 pages) and /note-examples (19), so the silo exists. The gaps: the gated pages show thin on-page content, so they under-rank (you sit at #9 for 'emdr note template', Supanote #1 with a free, ungated page). Un-gate them (show the full content free) and capture email with a soft opt-in, do not rebuild.
BUILD THIS
URL /templates/dap-note-template H1 DAP Note Template (with Example) [tool] Fillable template, full content free (soft opt-in, not a hard gate) H2 What a DAP note is H2 The template (copy/download) H2 A filled example H2 Generate it automatically [Try Mentalyc] FAQ + related templates
REQUIRED ELEMENTS
  • Schema: HowTo + FAQPage + BreadcrumbList
  • A soft email opt-in captures leads without the hard gate that costs you rankings today
  • Embed the note generator (Blueprint = product demo)

Why it wins: It turns reference traffic into emails (the funnel gap), and the embedded generator is a live product demo that AI Overviews cannot replace.

AI-OVERVIEW CAPTUREF. Answers / wiki silo

Silo hub: /answers (or /ai-scribe-wiki). Fixes the MOFU/TOFU AI invisibility.
Evidence: Twofold /ai-scribe-wiki uses real clinician questions as headings ('Is AI scribe HIPAA compliant?', 'Do insurance companies accept AI-generated notes?', 'Why does writing SOAP notes take so long?'), targeting the exact natural-language queries that trigger AI Overviews.
Mentalyc now: No Q&A or wiki silo. Across the AI sweep you are recommended on 0 of 29 top-funnel and 0 of 19 mid-funnel questions (your content is cited there, but the assistant never names you as the tool to use); only on buyer-stage questions are you the pick. Supanote ranks #1 for 'are AI therapy notes HIPAA compliant', where you do not appear.
BUILD THIS
URL /answers/are-ai-therapy-notes-hipaa-compliant H1 Are AI Therapy Notes HIPAA Compliant? [box] 40-word direct answer (AIO-extractable) H2 The short answer H2 What to check before you trust one H2 How Mentalyc handles it FAQ + related questions [CTA] Try Mentalyc
REQUIRED ELEMENTS
  • Schema: FAQPage / QAPage + BreadcrumbList
  • Seed from the question sweep: you are cited but recommended on 0 of 29 TOFU and 0 of 19 MOFU questions, so build the page that makes you the named answer
  • Lead each with a clean extractable answer block so Google/LLMs cite you

Why it wins: You are the most-cited domain already, but never the recommendation on mid- and top-funnel questions. This silo is built to make you the named, cited answer there.
